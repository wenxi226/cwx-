# Antigravity (React Bits, JS-CSS)

Official registry: https://reactbits.dev/r/Antigravity-JS-CSS.json
Documentation: https://reactbits.dev/animations/antigravity

`Antigravity.jsx` is the exact source from the registry, unchanged. This registry item contains one JSX file and no separate CSS file. The surrounding homepage layout is styled using plain CSS in `../HeroParticles.css`.

Registry dependencies: `@react-three/fiber@^9.3.0`, `three@^0.180.0`. Installed versions are captured in the project's `pnpm-lock.yaml`.

Website integration, cursor forwarding, lazy loading, reduced-motion handling and offscreen suspension live outside the original component.
